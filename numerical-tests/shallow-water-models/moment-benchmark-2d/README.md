# Two-dimensional moment benchmark

Public package updated: 2026-09-23.
Repository-relative path: `numerical-tests/shallow-water-models/moment-benchmark-2d/`.

Examples 1A and 1B use a smooth periodic initial condition on $[0,1]^2$, flat bottom, $G=1$, and final time $t=0.1$.
Both mean velocities and both moment families are active.
Example 1A measures same-equation discretization error; Example 1B compares with the inviscid vertically resolved hydrostatic parent system.
